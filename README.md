# Iris Flower Classification

## Project Overview

This project focuses on classifying Iris flowers into three species: Iris-setosa, Iris-versicolor, and Iris-virginica using machine learning.

The classification is performed using flower measurements such as sepal length, sepal width, petal length, and petal width.

## Objective

The main objective is to build and evaluate machine learning classification models that can predict the species of an Iris flower based on its measurements.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Workflow

1. Load the Iris dataset
2. Explore and understand the data
3. Perform data preprocessing
4. Analyze relationships between features
5. Split the data into training and testing sets
6. Train classification models
7. Evaluate model performance
8. Compare the models
9. Make sample predictions

## Models Used

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

## Evaluation

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## Result

The models achieved high classification performance on the test data. Logistic Regression and Decision Tree achieved the highest accuracy among the tested models.

## Conclusion

The project demonstrates how machine learning can be used to classify Iris flower species from their physical measurements. The results show that the selected classification models can effectively distinguish between the three Iris species.
